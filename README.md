# AI Coding Standards

Central, public instructions for Codex used by developers in VS Code and IntelliJ.

- `AGENTS.md` — global instructions and technology-specific routing.
- `standards/frontend.md` — JavaScript, TypeScript, React and frontend conventions.
- `standards/backend-java.md` — Java and Spring Boot conventions.
- `standards/security.md` — baseline security expectations.
- `standards/testing.md` — test quality and verification.
- `standards/code-review.md` — review checklist and output format.

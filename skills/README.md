## Skills
Set of skills used to automate development-review loop for feature development

### dev-loop
Co-ordinator/Spupervisor role which supervises completion of a given task using dev-build and dev-review agents. <br>
`dev-loop` always start with the currently set agent model. To avoid higher token consumption use `Terra` `low` or `medium`. 
The spawned agents start with `luna` `low` and may step up to `Terra` `medium` for repeated failure or complex tasks. 
The `dev-loop` agent could be instructed to spawn use high reasoning agents in the requirement or during the execution.

This skill expects a `repo-context.md` file to build the context while executing/spawning subagents. <br>
Please check example repo-context [here](https://github.com/ONPIER-PLATTFORM/thgbonus-interaction-service/blob/master/repo-context.md)

#### Execution
In IntelliJ AI chat window type bash `$dev-loop`. <br>
Provide a short feature name when asked.  <br>
Provide requirement when asked.   <br>
Let the magic begin :). <br>

The agent may ask for clarification in case of ambiguity or user approval to proceed.

##### CLI Execution
For cli usage execute `codex` in shell to start codex. The skills should be available to be executed. e.g `$dev-loop` 

### dev-build
Subagent skill spawned by `dev-loop` to plan and implement a feature

### dev-review
Independent Subagent skill spawned by `dev-loop` to review the artifacts generated by `dev-build` agent

## How to Install skills

### Global Application 
Copy `dev-loop`, `dev-build` and `dev-review` folder to  `.codex/skills` folder of the home directory or wherever codex has been installed. The skills should be applied globally.

### Local Application 
Create `.agents/skills` folder in repository at project level. Copy `dev-loop`, `dev-build` and `dev-review`  folders to the created `.codex` folder. The skill should be applied only for the specific repo.
